# 混合执行轻量首版：实际功能与边界

后续进展（同日）：用户改选独立虚拟机，已增加 VirtualBox 管理、脚本和客户机通道，详见 [虚拟机指南](../vm/README.md)。本文描述此前的本机轻量首版；其中“客户机 RPC 未实现”等不再代表最新代码。真实 Windows 客户机端到端测试仍待 ISO。

日期：2026-11-12。完整调研及引用见 [设计文档](HYBRID_EXECUTION_DESIGN.md)。

用户选择后台执行、桌面动作批准，并明确沙箱成本高时可以不要。本次因此实现本机轻量路径，不引入新依赖、浏览器镜像、虚拟机或常驻服务；沙箱内自动执行暂缓。

## 当前分配

| 能力 | 运行方式 | 当前限制 |
| --- | --- | --- |
| 历史检索、大脑整理、文本生成 | 后台 | 模型仍使用当前配置，历史不是新授权 |
| `workspace_tool` | 后台列出、读取、新建 UTF-8 文本 | 仅 `.windows-use/workspace`；1 MB；不覆盖；新建仍需设置中允许文件写入 |
| `scrape_tool` | 后台 HTTP 网页读取 | 不自动带入日常浏览器登录态，不支持所有动态网站 |
| `ui_control_tool inspect` | 只读探测 Invoke/Value/Toggle 能力 | 不调用鼠标，也不证明目标应用支持无焦点副作用操作 |
| UIA Invoke / SetValue / Toggle | 不移动鼠标的控件调用，先批准 | 未建立真实应用版本白名单；SetValue 读取回验，其余需后续观察验证 |
| 点击、输入、快捷键、滚动、拖动、应用/桌面切换与启动 | 单次批准后执行 | 仍共用本机设备；执行期间需短暂让出键鼠 |
| Shell、旧批量编辑/选择、无范围文件工具 | 混合入口禁用 | 模型工具列表隐藏，并在真实 Desktop 的 Registry 调用路径拦截 |
| Sandbox | 可选手动独立工作间 | 不接管 Agent 任务；无客户机执行器，无自动迁移 |

后台表示不注入物理输入，不表示 OS 隔离。没有承诺所有 Windows 软件都能后台操作。Word/WPS/Excel 专用接口、独立浏览器与后台 UIA 兼容清单留作后续按实际任务增加的适配器。

## 桌面批准流程

1. 模型提出具体工具与参数；确定性路由决定是否需要批准。
2. 风险权限和目标校验先通过，再弹出不主动抢焦点的批准卡。卡片展示目标窗口、动作和完整参数。
3. 一次批准只对应当前 worker 的一个随机请求 ID，不保存可复用批准票据；等待期间不调用模型。
4. 拒绝、关闭卡片、120 秒未回复、暂停或取消均不会批准该动作。新进程不能复用旧批准。隐藏到托盘时批准卡不自动弹出，点击托盘可查看待处理请求，隐藏期间也不会暂停超时计时。
5. 批准后重新读取界面，复核控件身份、位置、焦点和输入时间戳；校验超过 15 秒、发现新输入或界面变化即停止本次动作。
6. Registry 再做风险/目标校验后调用工具。下一步必须重新申请批准；不是整项任务永久放行。
7. 启用历史记录时保存 `action_intent`、`consent_requested`、`consent_closed`、可能的 `consent_invalidated` 与 `action_result`。批准记录不是执行成功记录。

界面变化或拒绝目前结束相关任务，保留既有结果，可从历史续接。没有做自动无限重试或跨任务恢复批准。

**实际边界**：输入时间戳只用于批准后的校验，未加入全局输入 Hook；不保证用户在一次长动作执行途中移动鼠标就能立即中断该动作。停止仍使用现有托盘/快捷键终止 worker，已产生的外部效果不可撤销。未来若增加多动作租约，必须补上连续输入撤销和持续动作边界测试。

批准基于控件快照，不是逐像素画面证明。纯画布、无法识别的控件、动态界面以及调用期间应用自身变化仍需谨慎验证；不把应用侧校验当作操作系统安全边界。

## 入口与兼容

- 从托盘退出旧桌宠后，双击 `frontend/start-desktop.vbs` 加载新版。
- 设置新增「执行环境」。后台与批准规则默认生效，不依赖沙箱选项。
- 旧配置自动补齐 `sandbox_network=False`，保留已有模型、大脑、视觉、Key 与历史。
- CLI/Python Agent 使用真实 Desktop 且没有批准回调时，前台工具拒绝执行；后台工具仍可使用。`auto_minimize=True` 被拒绝，防止构造参数绕过焦点批准。
- Registry 是本应用的工具执行边界；直接调用 Python Desktop 方法或替换它的自定义可信代码不属于 OS 隔离保证。

## 可选沙箱的成本

当前设备此前检测为 Windows 家庭版，官方不支持 Windows Sandbox，入口显示不可用；不尝试家庭版补丁、不启用系统组件、不要求用户升级。

受支持系统上，只有手动点击才创建一个 `.wsb` 并启动。映射本次 input 为只读、output 为可写；默认断网，关闭剪贴板、音频输入、摄像头及打印机重定向。配置申请 4096 MB 内存，不等同于实测占用。已有 Sandbox 进程时拒绝接管或关闭。

沙箱里没有主机软件或登录态，不自动下载软件。任务交换目录在项目 F 盘；Windows 自身沙箱镜像和系统缓存位置由系统管理，不保证它们也在 F 盘。用户不开沙箱时不分配客户机内存、不安装任何新东西。该可选入口可以完全不用。
